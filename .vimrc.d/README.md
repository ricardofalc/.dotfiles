# vimrc.d

`~/.vimrc` loads `*.vim` here, then `~/.vimrc.local`.

Put shared Vim config here. Put work-specific config in `~/.vimrc.local`.

Useful built-in commands:

- `:Explore` opens the file explorer.
- `:grep text .` searches below the current folder.
- `:copen`, `:cnext`, and `:cprev` navigate grep results.
- `=` auto-indents selected lines; `gg=G` auto-indents the whole file.
- `\h` opens the local quick help menu.
